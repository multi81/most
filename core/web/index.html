Папка обмена

Файлы из этой папки видны на сервере — на рабочем столе папка «Обмен», и наоборот.

На этом компьютере
На сервереРабочий стол → «Обмен» (появляется, пока открыт рабочий стол через «Мост»)
Настройка на маке — один раз
  1. Нажмите «Открыть Windows App».
  2. В строке меню вверху: Windows App → Настройки… (⌘ ,) → вкладка Основные.
  3. В строке про перенаправление папок (If folder redirection is enabled for RDP files…) → Выбрать папку… → Obmen в вашей домашней папке.
  4. Закройте окно рабочего стола и снова нажмите «Подключиться»: папка передаётся только при новом подключении.
  5. Если macOS спросит, дать ли Windows App доступ к папке, — разрешите.
На сервере: Рабочий стол → «Обмен» → «Obmen». Первое открытие может занять до минуты.

Новый сервер

Мастер сам подготовит чистый сервер Ubuntu 24.04 или 26.04: защита, AmneziaWG, Xray, свой DNS, управление устройствами и, по желанию, рабочий стол с RDP. В конце — готовый профиль.

1. Доступ к серверу
Рабочий стол KDE + RDPУдалённый рабочий стол с автовходом; до +30 минут к установке, нужно от 4 ГБ памяти
Google Chrome на сервереИз официального репозитория Google, браузер по умолчанию на рабочем столе
Claude на сервереОфициальное приложение Anthropic для Linux (бета) из их репозитория: чат и Claude Code на рабочем столе сервера, обновляется вместе с системой. Вход — вашей учётной записью Claude.
Порт AmneziaWG (UDP)443 лучше проходит защиту хостеров
Домен для маскировки (рекомендуется)Свой домен или поддомен с записью A на IP сервера, в Cloudflare — серое облачко (только DNS). Канал Reality будет выглядеть как обычный сайт на этом домене: мастер поставит на сервер страницу-заглушку с настоящим сертификатом. Под своим доменом Reality проходит фильтры провайдеров заметно лучше, чем под чужим сайтом. Без домена — маскировка под www.samsung.com.
Домен для CDN (по желанию)Другой домен в Cloudflare с записью A на IP сервера, оранжевое облачко — даст канал «Xray через CDN», он проходит, когда прямой путь до сервера режется. На время подготовки облачко серое, после — оранжевое.
2. Обследование
Отпечаток ключа сервера
Сверьте с тем, что показывает хостер (или выполните на сервере ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub). Это защита от подмены сервера.
3. Подготовка
Сервер готов

Профиль содержит пароль и ключи — храните его как пароль.

Осталось в Cloudflare
  1. DNS → запись домена → облачко оранжевое (Proxied).
  2. SSL/TLS → режим Full (strict).
  3. Network → WebSockets — включено.
  4. Правила «Always Use HTTPS» для этого домена не включайте — иначе не продлится сертификат.
